## 3. PANDUAN PENGUNGGAHAN KE SISTEM SANDI

Untuk memastikan dokumen dapat diproses secara optimal oleh modul **OCR PDF** dan mesin pencarian semantik **AI**:

1. **Format File yang Dianjurkan:**
   * Format berkas utama adalah **PDF** (*Portable Document Format*).
   * Dianjurkan menggunakan file PDF berbasis teks (*born-digital*) untuk ekstraksi teks instan berkecepatan milidetik.
   * Untuk dokumen pindaian (*scan* dari dokumen bertanda tangan/cap basah), pastikan resolusi minimal 200–300 DPI agar OCR dapat membaca naskah dengan akurat.

2. **Tata Cara Penamaan File (*File Naming Convention*):**
   * Format penamaan yang disarankan:
     ```text
     [Kategori]_[Nama_Dokumen]_[Tahun].pdf
     ```
   * Contoh:
     * `Kebijakan_SPMI_SYS_2021.pdf`
     * `Standar_Pendidikan_SPMI_SYS_2021.pdf`
     * `SOP_Bimbingan_Skripsi_Prodi_SI_2023.pdf`
     * `Pedoman_Pendidikan_SYS_2025.pdf`

3. **Langkah Pengunggahan di Aplikasi:**
   * Buka menu **Unggah Dokumen** pada bilah navigasi SANDI.
   * Pilih **Kategori Dokumen** sesuai tabel di atas pada menu *dropdown*.
   * Isikan **Judul Resmi Dokumen**, **Nomor SK/Surat** (jika ada), dan **Tahun Berlaku**.
   * Tarik (*drag-and-drop*) berkas PDF ke area uploader.
   * Sistem akan otomatis mengekstrak teks tiap halaman, menyimpan berkas ke Supabase Storage, dan memasukkan metadata ke database untuk kesiapan pencarian semantik.
